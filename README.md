# 📚 Book Recommendation System

A Machine Learning-based book recommendation system built using Streamlit that provides personalized book suggestions by analyzing user ratings and computing similarity between books using collaborative filtering.

## ⚙️ Features

* Top 50 popular books
* Personalized book recommendations
* Fast results using precomputed similarity


## 🧠 How It Works

This system uses **collaborative filtering** to recommend books.

* A **user-book rating matrix** is created
* Similarity between books is calculated using **cosine similarity**
* When a user searches for a book, the system finds similar books based on user ratings
* Recommendations are generated instantly using precomputed similarity scores
